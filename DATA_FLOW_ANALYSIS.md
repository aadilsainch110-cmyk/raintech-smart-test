**POSSIBLE CAUSES (in order of likelihood):**

1. **Firestore Security Rules Not Deployed** (90% likely)
   - The rules in FIRESTORE_RULES.md have been updated but not deployed to Firebase Console
   - Students cannot read questions even if they exist
   - This matches the pattern: teacher can save, student cannot read

2. **Questions Were Never Added** (8% likely)
   - Teacher created test but never added questions
   - Or teacher published test before adding questions
   - The test shows `questionCount: 0` in Firestore

3. **TestID Mismatch** (2% likely)
   - Questions saved with one testId
   - Student reading with different testId
   - Unlikely since same code path is used

4. **Network/Connection Issue** (<1% likely)
   - Cannot connect to Firestore
   - Would show network error

## Root Cause Assessment

**PRIMARY ISSUE:** Firestore Security Rules

The code is correct. The schema is consistent. The most likely cause is that the updated Firestore security rules in `FIRESTORE_RULES.md` have not been deployed to Firebase Console.

**SECONDARY ISSUE:** Test Creation Flow UX Issue

In `create_test_screen.dart`, after creating a test:
- The screen clears all fields
- Shows success dialog
- Does NOT navigate to the questions screen
- Teacher must manually go to Teacher Tests screen, find the test, then click "Questions"

This could lead to teachers publishing tests without adding questions.

## Proposed Fix

2. Select your project
3. Go to Firestore Database → Rules tab
